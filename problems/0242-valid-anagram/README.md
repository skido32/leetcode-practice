# 242. Valid Anagram

- 難易度: Easy
- リンク: https://leetcode.com/problems/valid-anagram/

## 問題（要約）
2つの文字列 `s` と `t` が与えられる。
`t` が `s` の **アナグラム** なら `true`、そうでなければ `false` を返す。

アナグラムとは、**文字を並べ替えるとちょうど同じ文字列になるもの**。
使われている文字の種類と、それぞれの個数が完全に一致している必要がある。

## 例
```
入力: s = "anagram", t = "nagaram"
出力: true
```
```
入力: s = "rat", t = "car"
出力: false
```

## 制約
- 1 <= s.length, t.length <= 5 * 10^4
- `s` と `t` は英小文字のみ

## 注意
- 返り値は必ず `true` か `false`（`nil` は不可）
- テストには長さ 5 * 10^4 の入力があり、**2秒以内**に終わらないと失敗する

## 発展
入力に Unicode 文字（日本語など）が含まれる場合、解き方をどう変える？
