# 242. Valid Anagram 振り返り

## 使ったパターン
- アナグラム = 文字ごとの個数が同じ → 数え上げて比べる
- v1: 英小文字だけなので長さ26の配列。`ch.ord - "a".ord` で 0〜25 番に変換
- v2（発展 / Unicode）: ハッシュ `{文字 => 個数}` で数える

## 計算量
| | 時間 | 空間 | 使える文字 |
|---|---|---|---|
| v1（26個の配列） | O(n) | O(1) | 英小文字だけ |
| v2（ハッシュ） | O(n) | O(n) | 何でも OK |

- 配列でも「n によって大きさが変わらない」なら空間 O(1)
- 制約を見て、配列（節約）かハッシュ（柔軟）かを選ぶ

## つまずいた点
- メソッドの書き方（`ord`, `each_char`, `key?`）
- `"a".ord` は 97。そのまま添字にすると範囲外 → `nil` → `nil + 1` で NoMethodError
- Ruby に `++` は無い。`x ++ 1` は足すだけで保存されない → `x += 1`
- `if key?` の分岐が逆、初回に入れる値が 0（正しくは 1）
- 見えない文字 `\x08` 再発 → `bin/t` が行番号を教えてくれるようにした

## 次に同じ問題を見たら
数え上げ問題。メソッドの書き方を思い出す:
- 配列版: `Array.new(26, 0)` / `ch.ord - "a".ord` / `+= 1`
- ハッシュ版: `Hash.new(0)` なら `h[ch] += 1` だけで数えられる（`key?` で分岐しても OK）
- 1行版: `s.chars.tally == t.chars.tally`
