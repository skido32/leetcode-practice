# 232. Implement Queue using Stacks

- 難易度: Easy
- リンク: https://leetcode.com/problems/implement-queue-using-stacks/

## 問題（要約）
**スタックを2つだけ** 使って、**キュー**（先に入れたものから先に出てくる入れ物。レジの行列）を作る。

クラス `MyQueue` に次のメソッドを作る:

| メソッド | やること |
|---|---|
| `push(x)` | `x` を列の **一番後ろ** に入れる |
| `pop` | 列の **一番前** の要素を取り出して返す |
| `peek` | 列の **一番前** の要素を返す（取り出さない） |
| `empty` | 列が空なら `true`、そうでなければ `false` |

### スタックとして使ってよい操作だけ
中身を入れる配列は、**スタックの操作だけ** で使うこと:
- 上に積む: `push(x)` / `<< x`
- 上から取り出す: `pop`
- 上を見る: `last` / `[-1]`
- 大きさ: `size` / `length` / `empty?`

`shift`（先頭を取り出す）や `first` / `[0]`（先頭を見る）などは **使えない**（テストで禁止している）。

## 例
```
q = MyQueue.new
q.push(1)    # 列: [1]
q.push(2)    # 列: [1, 2]（左が前）
q.peek       # => 1
q.pop        # => 1   列: [2]
q.empty      # => false
```

## 制約
- `1 <= x <= 9`
- `push` / `pop` / `peek` / `empty` は合わせて最大 100 回呼ばれる
- `pop` と `peek` は、列が空でないときだけ呼ばれる

## 発展
各操作を **ならして（平均して）O(1)** にできるか？（テストの最後の1つは、大量の操作で速さを確かめる）
