# 232. Implement Queue using Stacks 振り返り

## 使ったパターン
- スタック2本でキュー: **逆の逆は元に戻る**（スタックに入れると逆順、もう1本に移し替えるともう1回逆になって入れた順に戻る）
- `@a` = 入れる用、`@b` = 出す用
- **`@b` が空のときだけ** `@a` の中身を全部 `@b` に移す。`@b` に中身があれば、その一番上が行列の先頭
- `empty` は **2本とも** 空のときだけ true

## 計算量
| | push | pop / peek | 空間 |
|---|---|---|---|
| 毎回移して戻す（最初の版） | O(1) | O(n) | O(n) |
| `@b` が空のときだけ移す（発展） | O(1) | **ならして O(1)** | O(n) |

- ならして O(1)（償却 O(1)）: 1つの数字が筒から筒へ移るのは **最大1回**。5万回の操作でも移し替えは合計5万回くらいなので、1回あたり平均 O(1)。たまに O(n) の回があっても、全体で見れば O(1) ずつ

## つまずいた点
- 「スタックを2つだけ使って」の意味が分からなかった → 筒（上からしか触れない）2本で行列を作る、という意味
- `initialize` で `@` 付きの変数に配列を用意する（`@` なしだと、ほかのメソッドから見えない）
- `pop` で底の1個を覚えずに `@a = []` で捨てていた。`while` が最後の式だと返り値は `nil`
- `@b = @a` はコピーではなく **同じ配列に別の名前を付けただけ** → `@b.pop` で `@a` も減る
- 毎回 `@b = []` にしていた → 出す用の中身が消える。発展版では消さずに取っておく

## 次に同じ問題を見たら
入れる用と出す用の2本。「出す用が空のときだけ、入れる用を全部移す」。
```ruby
def pop
  move if @out.empty?
  @out.pop
end

def peek
  move if @out.empty?
  @out.last
end

def move
  @out << @in.pop until @in.empty?
end
```
