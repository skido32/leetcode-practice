# 20. Valid Parentheses 振り返り

## 使ったパターン
- スタック（最後に入れたものから取り出す入れ物。皿の積み重ね）
- 開きカッコは積む（`<<`）。閉じカッコが来たら、一番上（`[-1]`）が同じ種類なら取り出す（`pop`）、違えば false
- 閉じカッコの相手は「まだ閉じていない開きカッコのうち、**一番最後に開いたもの**」
- 最後にスタックが空でなければ、閉じられていない開きカッコが残っている → false

## 計算量
| | 時間 | 空間 |
|---|---|---|
| スタック | O(n) | O(n) ← 全部開きカッコだとスタックに n 個たまる |

## つまずいた点
- 文字を `` `(` ``（バッククォート）で囲んだ → Ruby ではシェルのコマンド実行になる。文字列は `"("` か `'('`
- `ch in [...]` と Python の書き方をした → Ruby は `[...].include?(ch)`（入れ物 → 要素の順）
- 最後に `return true` だけにしていた → `"(("` が true になる。最後にスタックが空かを確かめる

## 次に同じ問題を見たら
「対応するカッコ」「入れ子」「最後に開いたものから閉じる」= スタック。閉じ → 開きの対応はハッシュにすると if が1つで済む。
```ruby
pairs = { ")" => "(", "}" => "{", "]" => "[" }
stack = []
s.each_char do |ch|
  if pairs.key?(ch)
    return false if stack.pop != pairs[ch]
  else
    stack << ch
  end
end
stack.empty?
```
