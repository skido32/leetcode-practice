# 20. Valid Parentheses

- 難易度: Easy
- リンク: https://leetcode.com/problems/valid-parentheses/

## 問題（要約）
`(` `)` `{` `}` `[` `]` の6種類の文字だけでできた文字列 `s` が与えられる。

カッコの対応が正しければ `true`、そうでなければ `false` を返す。「正しい」とは次の3つを全部満たすこと:

1. 開きカッコは、**同じ種類** の閉じカッコで閉じられている
2. 開きカッコは、**正しい順番** で閉じられている（内側から先に閉じる）
3. 閉じカッコには、必ず対応する同じ種類の開きカッコがある

## 例
```
入力: s = "()"
出力: true
```
```
入力: s = "()[]{}"
出力: true
```
```
入力: s = "(]"
出力: false   （種類が違う）
```
```
入力: s = "([)]"
出力: false   （閉じる順番が違う。( より先に [ を閉じる必要がある）
```
```
入力: s = "{[]}"
出力: true
```

## 制約
- `1 <= s.length <= 10^4`
- `s` は `()[]{}` のどれかの文字だけでできている
