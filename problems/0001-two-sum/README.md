# 1. Two Sum

- 難易度: Easy
- リンク: https://leetcode.com/problems/two-sum/

## 問題（要約）
整数の配列 `nums` と整数 `target` が与えられる。
`nums` の中から **足すと `target` になる2つの要素** を選び、その **インデックス（位置）** を配列で返す。

- 答えはちょうど1組だけ存在する
- 同じ要素を2回使ってはいけない（同じ値が別の位置にあるのは OK）
- 返す2つのインデックスの順番はどちらでもよい

## 例
```
入力: nums = [2, 7, 11, 15], target = 9
出力: [0, 1]
説明: nums[0] + nums[1] = 2 + 7 = 9
```
```
入力: nums = [3, 2, 4], target = 6
出力: [1, 2]
```
```
入力: nums = [3, 3], target = 6
出力: [0, 1]
```

## 制約
- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- 答えはちょうど1つ
