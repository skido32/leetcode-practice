# 1. Two Sum 振り返り

## 使ったパターン
- v1: 全探索（各要素について、相方を配列から探す）
- v2: ハッシュで「値 → インデックス」を覚えておき、相方を O(1) で引く

## 計算量
| | 時間 | 空間 |
|---|---|---|
| v1 (`nums.index`) | O(n²) | O(1) |
| v2 (Hash) | O(n) | O(n) |

- `nums.index` は中で端から探すので O(n)。ループの中で呼ぶと O(n²) になる（隠れたループ）
- v2 はメモリを使って速くした（時間と空間のトレードオフ）
- 空間計算量 = 追加で使うメモリのピーク（入力は数えない）

## つまずいた点
- それぞれのメソッドが浮かばなかった（`Array#index`, `nil?`, `each_with_index`, Hash）
- v2 で `h[num]` と書き、自分自身を探していた → 探すのは相方の `h[diff]`
- 1文字の見えない制御文字（`\x08`）で SyntaxError。`Invalid char` が出たらその行を打ち直す

## 次に同じ問題を見たら
「足して target」= 相方（`target - num`）を探す問題。相方の位置はハッシュ `{値 => インデックス}` で O(1) で引ける。

## 復習（2026-11-21）
- 何も見ずに、最初からハッシュの O(n) 版で書けた
- 抜けていたのは「同じ要素を2回使わない」チェック（`[3, 2, 4]`, 6 → `[0, 0]`）。Actual に同じ番号が並んだらこれを疑う
- 1回のループ版: 「先に相方を探してから、自分をハッシュに入れる」順番にすれば、自分自身を見つけることがなくなり、このチェック自体が不要になる
- → 1回ループ版を実装済み。`hash.key?(diff)` だけで判定（自分自身のチェック不要）:
```ruby
nums.each_with_index do |num, i|
  diff = target - num
  return [i, hash[diff]] if hash.key?(diff)   # 先に相方を探す
  hash[num] = i                               # 後で自分を入れる
end
```
