# 344. Reverse String 振り返り

## 使ったパターン
- 二つのポインタ: 左端と右端を入れ替えながら、真ん中に向かって進む
- 入れ替えるペアは `i` ⇔ `s.size - i - 1`、ループは半分（`0...s.size/2`）まで

## 計算量
| | 時間 | 空間 |
|---|---|---|
| 両端から入れ替え | O(n) | O(1) |

## つまずいた点
- `s / 2` と書いて配列を割ろうとした → 長さは `s.size`
- `a = s[i]` は値のコピー。`a` を変えても `s` は変わらない → `s[i] = ...` に直接代入する
- `..`（最後を含む）だと偶数の長さで1回多く回り、入れ替えが戻る → `...`（最後を含まない）
- `s[-1]` はエラーにならず最後の要素を返すので、番号のミスに気づきにくい

## 次に同じ問題を見たら
両端から入れ替えて真ん中で止める。定番の形:
```ruby
left, right = 0, s.size - 1
while left < right
  s[left], s[right] = s[right], s[left]
  left += 1
  right -= 1
end
```

## 復習（2026-11-22）
- `/hint` なしで解けた。`s.size` と「s に直接代入（多重代入）」は自分で書けた
- ループの範囲（`..`）だけ再発 → `(0..s.size/2 - 1)` で修正。`(0...s.size/2)` と同じ意味
- 偶数の長さだけ失敗したら、ループが1回多い（真ん中のペアをもう一度入れ替えて戻している）
