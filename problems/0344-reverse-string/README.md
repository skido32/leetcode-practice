# 344. Reverse String

- 難易度: Easy
- リンク: https://leetcode.com/problems/reverse-string/

## 問題（要約）
1文字ずつの配列 `s` が与えられる。この配列を **逆順に並べ替える**。

- 新しい配列を作って返すのではなく、**渡された配列 `s` そのものを書き換える**（in-place）
- 追加で使うメモリは **O(1)** にすること
- 返り値は使われない（何を返してもよい）

## 例
```
入力: s = ["h", "e", "l", "l", "o"]
実行後の s: ["o", "l", "l", "e", "h"]
```
```
入力: s = ["H", "a", "n", "n", "a", "h"]
実行後の s: ["h", "a", "n", "n", "a", "H"]
```

## 制約
- 1 <= s.length <= 10^5
- `s[i]` は表示可能な ASCII 文字

## このリポジトリでのルール
- 面接の練習なので、`reverse` / `reverse!` は使わないこと（テストで禁止しています）
- 長さ 10^5 のテストが **2秒以内** に終わらないと失敗する
