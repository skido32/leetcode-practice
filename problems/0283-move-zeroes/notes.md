# 283. Move Zeroes 振り返り

## 使ったパターン
- 二つのポインタ（同じ方向に進む版）: `j` = 読む指（毎回進む）、`i` = 書く指（0 以外を見つけたときだけ進む）
- 言い換え: 「0 を後ろへ」＝「0 以外を前から詰める」

## 計算量
| | 時間 | 空間 |
|---|---|---|
| 読む指・書く指で入れ替え | O(n) | O(1) |

## つまずいた点
- 最初の方針が浮かばず、ヒント段階3（手順）まで使った
- 見方を逆にする（0 を動かす → 0 以外を詰める）のがカギだった

## 発展（操作回数を減らす）
- `i == j` のときは自分自身との入れ替えなので `if i != j` で省く → 実装済み

## 次に同じ問題を見たら
「条件を満たすものを前に詰める」= 読む指と書く指。344 の両端から近づく版とは別の形。
```ruby
i = 0
nums.each_index do |j|
  next if nums[j] == 0
  nums[i], nums[j] = nums[j], nums[i]
  i += 1
end
```
