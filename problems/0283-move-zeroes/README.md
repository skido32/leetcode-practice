# 283. Move Zeroes

- 難易度: Easy
- リンク: https://leetcode.com/problems/move-zeroes/

## 問題（要約）
整数の配列 `nums` が与えられる。**0 をすべて配列の後ろに移動** する。

- 0 以外の要素は、**元の並び順を保つ** こと
- 新しい配列を作らず、**渡された `nums` そのものを書き換える**（in-place）
- 返り値は使われない

## 例
```
入力: nums = [0, 1, 0, 3, 12]
実行後の nums: [1, 3, 12, 0, 0]
```
```
入力: nums = [0]
実行後の nums: [0]
```

## 制約
- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1

## このリポジトリでのルール
- 練習のため、配列をまとめて処理するメソッド（`sort`, `select`, `reject`, `delete`, `partition`, `compact`, `map` など）は `nums` に使えない（テストで禁止）
- 長さ 10^4 のテストが **2秒以内** に終わらないと失敗する
