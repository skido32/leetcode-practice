# 88. Merge Sorted Array

- 難易度: Easy
- リンク: https://leetcode.com/problems/merge-sorted-array/

## 問題（要約）
小さい順に並んだ（昇順の）2つの整数配列 `nums1` と `nums2` がある。
`nums2` を `nums1` に合体させて、**`nums1` 全体を昇順に並んだ1つの配列** にする。

- `nums1` の長さは `m + n`。先頭の `m` 個が本当のデータで、**後ろの `n` 個は 0 が入った空きスペース**（中身は無視してよい）
- `nums2` の長さは `n`
- 新しい配列を返すのではなく、**`nums1` そのものを書き換える**（in-place）。長さは `m + n` のまま
- 返り値は使われない

## 例
```
入力: nums1 = [1, 2, 3, 0, 0, 0], m = 3, nums2 = [2, 5, 6], n = 3
実行後の nums1: [1, 2, 2, 3, 5, 6]
説明: 本当のデータは [1, 2, 3] と [2, 5, 6]。後ろの 0 は空きスペース
```
```
入力: nums1 = [1], m = 1, nums2 = [], n = 0
実行後の nums1: [1]
```
```
入力: nums1 = [0], m = 0, nums2 = [1], n = 1
実行後の nums1: [1]
説明: m = 0 なので nums1 に本当のデータは無い。0 は空きスペース
```

## 制約
- nums1.length == m + n
- nums2.length == n
- 0 <= m, n <= 200
- 1 <= m + n <= 200
- -10^9 <= nums1[i], nums2[j] <= 10^9

## このリポジトリでのルール
- 練習のため、`nums1` に `sort` / `sort!` / `replace` / `concat` などは使えない（テストで禁止）
