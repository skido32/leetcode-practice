# 121. Best Time to Buy and Sell Stock 振り返り

## 使ったパターン
- 「ここまでの最小値を変数で持ち歩く」1回の走査
- 言い換え: 「売る日を決めたら、一番いい買い日は **その日より前の最安値**」
- 持ち歩く変数は2つ: `最安値` と `最大利益`（初期値 0 = 何もしない）

## 計算量
| | 時間 | 空間 |
|---|---|---|
| 全部の組み合わせ（二重ループ） | O(n²) | O(1) ← 10万日だと時間切れ |
| 最安値を持ち歩く | O(n) | O(1) |

## つまずいた点
- 方針はヒント段階3（手順）まで使った。手順を見てからは一発で正しく書けた
- ブロック変数を `p` にした → Ruby では `p` はデバッグ表示のメソッド名。動くが、中で `p` で表示できなくなる → `price` などにする
- 変数名 `max` は配列の `max` メソッドと紛らわしい → `max_profit_so_far` / `best` など

## 次に同じ問題を見たら
「後の日 − 前の日 の最大」= 前から1回なめて、**ここまでの最安値** を持ち歩く。毎日「今日売ったら？」を計算して最大を更新。
```ruby
min_price = prices[0]
best = 0
prices.each do |price|
  best = price - min_price if price - min_price > best
  min_price = price if price < min_price
end
best
```
