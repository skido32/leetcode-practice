# 121. Best Time to Buy and Sell Stock

- 難易度: Easy
- リンク: https://leetcode.com/problems/best-time-to-buy-and-sell-stock/

## 問題（要約）
配列 `prices` の `prices[i]` は、i 日目の株の値段。

どこか1日に **1回だけ買い**、それより **後の日** に **1回だけ売る**。
得られる利益（売値 − 買値）の最大値を返す。
どう売買しても利益が出ない（損しかしない）なら `0` を返す（＝何もしない）。

- 売る日は必ず買う日より後（同じ日・前の日には売れない）

## 例
```
入力: prices = [7, 1, 5, 3, 6, 4]
出力: 5
説明: 2日目（値段1）に買って、5日目（値段6）に売ると 6 - 1 = 5。
      1日目に買って…ではなく、「7で売って1で買う」は順番が逆なのでダメ。
```
```
入力: prices = [7, 6, 4, 3, 1]
出力: 0
説明: ずっと値下がりしているので、どこで買っても損。何もしないのが最善。
```

## 制約
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`
