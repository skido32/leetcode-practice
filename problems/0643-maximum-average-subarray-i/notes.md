# 643. Maximum Average Subarray I 振り返り

## 使ったパターン
- スライディングウィンドウ（固定幅 k）: 窓を1つ右にずらすたびに **出ていく数を引いて、入ってくる数を足す**
- スタート `n` の窓: 入ってくる = `nums[n + k - 1]`、出ていく = `nums[n - 1]`
- 「今の窓の合計」と「今までで一番大きい合計」は **別の変数**（121 の最安値・最大利益と同じ形）

## 計算量
| | 時間 | 空間 |
|---|---|---|
| 全部の窓をそれぞれ足す（二重ループ） | O(n × k) | O(1) ← 10万 × 5万で時間切れ |
| スライディングウィンドウ | O(n)（最初の窓 k 回 + ずらす n − k 回） | O(1) |

## つまずいた点
- 最初「ソートして大きい順に k 個」と考えた → **連続** という条件を見落としていた
- 最初の窓の合計で、`total += n`（番号）を足していた → `nums[n]`（値）。88 復習と同じ「番号と値の取り違え」
- 最初の窓の範囲を `(0..nums.size - k)` にしていた → 最初の窓は `0` 〜 `k - 1`
- 出ていく数を `nums[n]` にしていた → `nums[n - 1]`。例1で n = 1 を手で追うと分かる
- 合計が増えるときだけ足していた → 「今の窓の合計」は毎回必ず更新し、最大は別の変数で持つ
- `/ 4` と固定していた、整数どうしの割り算 `51 / 4 == 12` → `/ k.to_f`（または `fdiv(k)`）

## 次に同じ問題を見たら
「連続する k 個」= 固定幅の窓。最初の窓を作って、あとは「−出ていく +入ってくる」でずらす。
```ruby
total = nums[0, k].sum
best = total
(k...nums.size).each do |i|
  total += nums[i] - nums[i - k]
  best = total if total > best
end
best.fdiv(k)
```
