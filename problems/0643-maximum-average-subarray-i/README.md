# 643. Maximum Average Subarray I

- 難易度: Easy
- リンク: https://leetcode.com/problems/maximum-average-subarray-i/

## 問題（要約）
整数の配列 `nums` と整数 `k` が与えられる。

`nums` の中で **連続して並んだ k 個** の数を選ぶ。選び方はいろいろあるが、その k 個の **平均** が一番大きくなるときの平均値を返す。

- 答えは小数（Float）。誤差 `10^-5` 未満なら正解

## 例
```
入力: nums = [1, 12, -5, -6, 50, 3], k = 4
出力: 12.75
説明: 連続する4個の選び方は3通り
      [1, 12, -5, -6]  → 平均 0.5
      [12, -5, -6, 50] → 平均 12.75  ← 最大
      [-5, -6, 50, 3]  → 平均 10.5
```
```
入力: nums = [5], k = 1
出力: 5.0
```

## 制約
- `n == nums.length`
- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
