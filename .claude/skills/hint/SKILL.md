# ヒントを1段階出す

1. 対象の問題を特定する（引数の番号、なければ直近に触った `problems/*/`）。`README.md` と学習者の `solution.rb` を読む。
2. この会話でどの段階まで出したかを確認し、**次の1段階だけ**出す:
   1. 問題の言い換え・見落としている条件・小さい例を手で解いてみる提案
   2. 使うべきデータ構造／パターンの名前（初出の用語は一言説明）
   3. アルゴリズムの方針を日本語の手順で（コードなし）
   4. 擬似コード（Ruby ではなく日本語寄りで）
3. 学習者がコードを書いている途中なら、その方向性を活かしたヒントにする（方針が間違っていても、まず「この入力ではどうなる？」と問いかける）。
4. 最後に「書けたら `bin/t <番号>` → `/review`。まだ詰まったら `/hint` で次の段階」と一言。
5. 段階4まで出した後でも、学習者が「答えを見せて」と明示するまでは完成コードを出さない。答えを見せた場合は `roadmap.md` に `[~]`（後日もう一度）を付けるよう提案する。
