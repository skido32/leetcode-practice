# 今日やる問題を選ぶ

ペースの目標: **1日 新しい問題2問 + 期限の来た復習**（2026-11-22 に本人と決定。本番は 2027年3〜4月）

1. `roadmap.md` と `progress.md` を読み、今日の日付を確認する。
2. 現状を短くまとめる:
   - 解いた数、章ごとの達成状況、`[~]`（要復習）の問題
   - **今日すでに解いた問題**（progress.md の今日の日付の行）と、今日の残りノルマ
   - ペースの確認: 直近7日の「新しい問題」の数（目標は 14問/週）。遅れていれば一言だけ伝える（責めない）
3. 今日のメニューを決める:
   - **復習**: 解いた日から3日以上たった `[~]` の問題は全部、今日の復習に入れる（多すぎる日は古いものから2問まで、残りは翌日へ）
   - **新しい問題**: roadmap の最初の未チェック問題から、今日の残りノルマ分（最大2問）
   - 同じパターンで2問連続「答えを見た」なら、そのパターンの概念を `/explain` で復習することを提案
   - おすすめの順番: 復習 → 新しい問題（復習で頭を温めてから）
4. メニューを表で示す（問題名と章名だけ。**解き方は言わない**）。それぞれの始め方も案内する:
   - 新しい問題: `/new <番号>`
   - 復習: 前回の `solution.rb` を `attemptN.rb`（N は空いている番号）に移し、空の `solution.rb` を用意してから始める。学習者が了承したらこちらで準備してよい
5. 学習者が了承したら、最初の1問をそのまま用意してよい。
