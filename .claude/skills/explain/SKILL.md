# 概念を解説する

1. 引数の概念（例: ハッシュ、二つのポインタ、再帰、O記法、Ruby の `each_with_object`）を初心者向けに説明する:
   - 一言で言うと何か → 身近なたとえ → 小さな具体例を手でトレース
   - Ruby での基本的な書き方（短いコード例。LeetCode の特定の問題の答えにはしない）
   - 計算量
   - どんな問題文の「サイン」が出たら使うか
2. 最後に理解確認のミニクイズを1問出し、学習者の答えを待つ。
3. 学習者が今取り組み中の問題があっても、その問題の解答に直結する説明は避ける（ヒントが必要なら `/hint` を案内）。
